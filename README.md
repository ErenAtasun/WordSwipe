## 📖 About the Project

WordSwipe is a mobile word puzzle game inspired by popular swipe-based word games. Players create words by connecting adjacent letters, aiming to complete each level by finding all hidden words.

The project was developed with a strong focus on clean architecture, maintainable code, and reusable game systems. Rather than only recreating existing mechanics, the goal was to build a scalable foundation that can easily support new levels, gameplay features, and future improvements.

---

## ✨ Features

* 🎯 Swipe-based word selection
* 🧩 Hidden word puzzle mechanics
* 📱 Mobile-friendly user interface
* ⚡ Smooth and responsive gameplay
* 💡 Hint system
* 🏆 Progressive level structure
* 🔄 Modular and scalable project architecture
